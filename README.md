# Student-Task-Tracker-App
Student Task Tracker is a task management application designed to help students organize their daily tasks, assignments, and schedules efficiently.

🚀 Features

👤 User Registration & Login

📝 Add / Edit / Delete Tasks

📅 Task Deadline Management

✅ Mark Tasks as Completed

🔍 Filter Tasks (Completed / Pending)

📊 Dashboard Overview


🛠️ Tech Stack
🔹 Frontend

Flutter 
Dart

🔹 Backend

PHP 
REST API
MySQL Database

🔹 Tools

Git & GitHub
Android Studio
XAMPP 


🚀 How to Run
Backend
Place backend folder inside XAMPP htdocs
Start Apache & MySQL

Frontend
Run flutter pub get
Update API base URL
Run flutter run
